# Francisco Arroyo — Software Engineer

Personal portfolio highlighting professional experience, technical skills, and contact links.

The live site is published at [thedevfrancorr.github.io/software-engineer-portfolio](https://thedevfrancorr.github.io/software-engineer-portfolio/).

## Languages

The website is available in Spanish and English. Use the language selector in the navigation bar to switch languages.

## Run locally

Install dependencies with `npm install`, then start the development server with `npm start`. Create a production build with `npm run build`.

Every push to `main` builds and deploys the site through GitHub Actions and GitHub Pages.

## Project structure

- `src/Components/` contains the page sections.
- `src/translations.js` contains the Spanish and English interface content.
- `src/images/` contains the portfolio's images and social icons.

All portfolio content and configuration describe Francisco Arroyo's professional profile.
