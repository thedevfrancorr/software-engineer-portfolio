# Francisco Arroyo — Engenheiro de software

Portfólio pessoal com experiência profissional, competências técnicas e links de contato.

O site publicado está disponível em [thedevfrancorr.github.io/software-engineer-portfolio](https://thedevfrancorr.github.io/software-engineer-portfolio/).

## Idiomas

O site está disponível em espanhol e inglês. Use o seletor de idioma na barra de navegação para alternar entre eles.

## Execução local

Instale as dependências com `npm install` e inicie o servidor de desenvolvimento com `npm start`. Gere uma compilação de produção com `npm run build`.

Cada atualização na branch `main` compila e publica o site usando GitHub Actions e GitHub Pages.

## Estrutura do projeto

- `src/Components/` contém as seções da página.
- `src/translations.js` contém os textos da interface em espanhol e inglês.
- `src/images/` contém as imagens e os ícones de redes sociais.

Todo o conteúdo e a configuração do portfólio descrevem o perfil profissional de Francisco Arroyo.
