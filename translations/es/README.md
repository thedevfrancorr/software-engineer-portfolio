# Francisco Arroyo — Ingeniero de software

Portfolio personal con experiencia profesional, competencias técnicas y enlaces de contacto.

El sitio publicado está disponible en [thedevfrancorr.github.io/software-engineer-portfolio](https://thedevfrancorr.github.io/software-engineer-portfolio/).

## Idiomas

El sitio web está disponible en español e inglés. Usa el selector de idioma de la barra de navegación para cambiar de idioma.

## Ejecución local

Instala las dependencias con `npm install` e inicia el servidor de desarrollo con `npm start`. Genera una compilación de producción con `npm run build`.

Cada actualización de la rama `main` compila y publica el sitio mediante GitHub Actions y GitHub Pages.

## Estructura del proyecto

- `src/Components/` contiene las secciones de la página.
- `src/translations.js` contiene los textos de la interfaz en español e inglés.
- `src/images/` contiene las imágenes y los iconos de redes sociales.

Todo el contenido y la configuración del portfolio describen el perfil profesional de Francisco Arroyo.
